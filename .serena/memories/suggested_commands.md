# Suggested Commands: introspection_note_mvp

## Development
- **Run project**: `flutter run`
- **Clean project**: `flutter clean`
- **Get dependencies**: `flutter pub get`
- **Code generation**: `dart run build_runner build --delete-conflicting-outputs` (required for `freezed` and `json_serializable`)

## Testing
- **Run all tests**: `flutter test`

## Localization
- **Generate localization files**: (If using intl_utils) `dart run intl_utils:generate`
